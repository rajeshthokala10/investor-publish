# Templates

- `report.css`: styles for the HTML/PDF report and the infographic cover (screen, mobile, print/A4).
- The infographic markup is generated by `harness/infographic.py` (layout modelled on a
  newspaper market graphic: headline, hero + KPI tiles, chart/highlights/drivers row,
  chart/matrix/outlook row, corridor strip, source footer).
- Markdown structure is produced by `harness/report.py::build_markdown` (10 fixed sections).
